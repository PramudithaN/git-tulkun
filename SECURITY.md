# Security Policy

## Supported Versions

We actively provide security fixes and maintenance updates for the latest major release and action tag.

| Version | Supported          |
| ------- | ------------------ |
| 1.x / v1 | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive bug within **git-tulkun**, please report it responsibly rather than opening a public issue.

### How to Report

1. **GitHub Security Advisory (Preferred)**:
   - Navigate to the [Security Advisories tab](https://github.com/PramudithaN/git-tulkun/security/advisories) of this repository.
   - Click **"Report a vulnerability"** to open a private advisory draft.

2. **Direct Email**:
   - Alternatively, you can email: **pramudithanadun@gmail.com** with the subject `[SECURITY] git-tulkun vulnerability report`.
   - Please include:
     - A description of the issue.
     - Steps or a minimal proof-of-concept to reproduce it.
     - Potential impact.

### What to Expect

- **Initial Response**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment**: We will provide a status update on whether the issue is confirmed and outline a fix timeline.
- **Resolution**: Once patched, a new release and announcement will be made with appropriate credit given to the reporter (if desired).
