# Welcome to the `git-tulkun` Wiki

**`git-tulkun`** is an open-source procedural pixel-art cetacean generator designed for GitHub profile `README.md` files. Inspired by the majestic Tulkun leviathans of Pandora (*Avatar: The Way of Water*), each whale swims in a seamless 15 FPS looping animation that grows and evolves based on your real GitHub contribution activity.

### Key Highlights

1. **Annual Lifecycle Reset**: On January 1st, every Tulkun resets to a **Stage 1: Baby Calf**, growing across **5 biological stages** toward a battle-scarred **Stage 5: Adult Bull** as you commit code.
2. **Rolling 365 Option**: If you prefer a continuous companion year-round without seasonal resets, configure `window: rolling`.
3. **Dynamic Language Colors**: No static spritesheets. The whale's dithered skin, belly, and glowing sensor crest organ take their colors from the official GitHub hex values of your top 3 programming languages.
4. **Zero Repository Bloat**: Automatically pushes `.gif`, `.png`, and `1280×640` share cards to an isolated orphan `output` branch, keeping your `main` commit history clean.
5. **Interactive Web Generator**: Preview any GitHub username or compare two developers side-by-side at [pramudithan.github.io/git-tulkun](https://pramudithan.github.io/git-tulkun/).
